# TC-A11Y-001 — High contrast, keyboard focus and non-colour status

This case extends the saved-contrast preference in J09–J12 workstream 6a. Dated
execution results are recorded separately in the test history.

Sources:
the high-contrast scenario in `src/test/browser/milestone-check.cjs`, the
existing skip-link keyboard check in `src/test/browser/market-desk.cjs`, and the
CSS contrast overrides in `src/main/resources/static/css/market-desk.css`.

## Preference and application

`POST /preferences` saves locale and contrast for the single local user. The
rendered page applies the saved locale as `<html lang>` and the contrast choice
as `<body data-contrast="high">` or `"normal"`. The preference is applied on
every page, including budget, saved, privacy, and history pages.

High contrast changes the page/surface/ink/muted colours and strengthens link
underlines. The saved choice survives navigation and restart; it does not change
the source data.

## Contrast, focus and non-colour checks

With Traditional Chinese and high contrast selected, the milestone browser
script:

1. computes the WCAG relative-luminance contrast ratio of the body text against
   the body background and requires at least 7:1;
2. opens `/saved` and requires the status pill to have a visible border in high
   contrast, so status is not conveyed by colour alone;
3. opens `/preferences` and presses Tab until focus reaches the main content,
   then requires a 4 px focus outline.

The baseline browser suite separately checks the skip link: Tab focuses **Skip to
content**, Enter moves focus to the `#main-content` landmark. It also checks
375, 768, 1024, and 1440 px layouts for horizontal overflow and clipped prices.

## Scope and limits

These checks are automated evidence for the stated colours, outline width,
border presence, and layout. They do not prove a full WCAG 2.2 audit, screen
reader announcements, every browser engine, every zoom level, or every user
preference combination. Chromium through Playwright is the only browser tested.
A human visual pass and a screen-reader spot check remain recommended.
