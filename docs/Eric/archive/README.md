# Historical requirements and proposals

These eight original documents are retained as evidence of early requests,
alternatives, and rejected assumptions. They are not implementation instructions.
Accounts, PostgreSQL, live list synchronization, and other proposals in these
files do not override the [current project scope](../../project-scope.md).

Some originals describe persona work as interviews. The current
[product description](../../product-description.md#users) identifies the request
source as AI role-play; these files do not establish that human interviews took
place. The originals are preserved without rewriting their historical wording.

For current work, start with the [project README](../../../README.md). Use the
[J05–J08 plan](../../Plan/tracking-alerts-budgets-reminders-j05-j08.md) for the next
milestone, after its relevant decision gates are resolved.
